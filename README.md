# User Registration (Flutter)

Lab 6: registration screen with form validation.

## Features

- Form with GlobalKey<FormState> and TextEditingController
- Full Name, Email, Password, Confirm Password fields with validation
- Role dropdown (Student / Teacher / Developer)
- Checkbox "I accept the Terms and Conditions"
- Error text under invalid fields, success SnackBar, data printed in terminal

## How to run

```
flutter pub get
flutter run
```
